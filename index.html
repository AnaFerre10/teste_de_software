Fundamentos

O que é Teste de Software?

O teste de software é o processo disciplinado de avaliar a qualidade e a funcionalidade de uma aplicação. Não se trata de "clicar aleatoriamente", mas de validar hipóteses de comportamento esperado contra resultados reais.

auth.spec.js JavaScript 
// Um teste é uma asserção sobre o comportamento esperado da aplicação
describe('Autenticação de Usuário', () => {
  it('deve bloquear o acesso quando as credenciais forem inválidas', async () => {
    const resposta = await authService.login('user@test.com', 'senha_errada');
    
    expect(resposta.status).toBe(401);
    expect(resposta.authenticated).toBe(false);
  });
});

Estudos de Caso

Falhas Históricas Causadas por Bugs

Exemplos reais de como a ausência de cobertura de testes ou validações inadequadas geraram impactos bilionários.

Falha de Sistema 1996

Foguete Ariane 5 (Voo 501)

O foguete destruiu-se segundos após o lançamento. Um estouro de memória ocorreu ao tentar converter um número de 64 bits para 16 bits no código do sistema de navegação.

Lição: Código legado deve ser retestado integralmente quando reaproveitado em novas condições operacionais.
Sistemas Críticos 1985 – 1987

Therac-25

Uma falha do tipo "Condição de Corrida" (Race Condition) no software de controle da máquina de radioterapia resultou na liberação de doses letais de radiação em pacientes.

Lição: Ambientes concorrentes exigem testes de concorrência e hardware em malha fechada (HIL).
Integração 1999

Mars Climate Orbiter

A sonda da NASA foi destruída ao entrar na atmosfera de Marte porque um módulo utilizava o sistema de unidades imperiais, enquanto o outro esperava o sistema métrico.

Lição: Testes de integração entre módulos de fornecedores diferentes são fundamentais.
Implantação 2012

Knight Capital Group

A implantação de código não testado em um servidor ativou rotinas obsoletas. O sistema executou ordens financeiras erráticas, gerando um prejuízo de US$ 440 milhões em 45 minutos.

Lição: Deploys precisam de validação e sanitização estrita do ambiente de produção real.
